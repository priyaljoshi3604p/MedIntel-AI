# RAG Source Documents

This directory contains approved reference documents used by the
MedIntel-AI knowledge retrieval system.

Before adding a document:

1. Verify the source.
2. Record the source in `sources.md`.
3. Record the document in `manifest.json`.
4. Check the document's usage and redistribution terms.
5. Confirm that it contains no patient-identifiable information.

Documents should remain traceable to their original source.
