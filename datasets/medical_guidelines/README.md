# Medical Guidelines Dataset

This directory contains trusted medical reference materials used
by the MedIntel-AI knowledge retrieval system.

## Requirements

Reference materials should:

* Come from authoritative medical organizations or institutions.
* Be legally available for use.
* Have their source and publication/update date documented.
* Be stored in a format suitable for retrieval.
* Not contain patient-identifiable information.

## Intended Use

The materials are used to provide supporting medical knowledge to
the AI system. Retrieved information should be presented as
decision-support information and should not replace evaluation by
a qualified healthcare professional.

## Source Tracking

Each reference document should record:

* Title
* Organization/author
* Publication date
* URL or source
* License/usage information
* Date added to the dataset
